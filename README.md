# Spotify Analytics Dashboard 🎵📊
## Overview

This project is an interactive Spotify Analytics Dashboard created using Microsoft Power BI. The dashboard analyzes Spotify music data to uncover insights about popular artists, tracks, genres, and listening trends through dynamic visualizations.

The dataset used for this project was sourced from Kaggle and transformed into an interactive business intelligence dashboard for better data exploration and storytelling.

## Features

* Interactive dashboard with filters and slicers
* Analysis of top artists and tracks
* Music popularity and streaming trends
* Genre-wise insights and comparisons
* User-friendly data visualizations
* Clean and organized dashboard layout
  
## Tools & Technologies Used

* Power BI
* Data Visualization
* Data Cleaning
* DAX
* Kaggle Dataset

## Dataset

The dataset for this project was obtained from Kaggle and contains Spotify music-related data used for analysis and visualization purposes.

* Transform raw music data into meaningful insights
* Practice dashboard development and storytelling with data
* Improve analytical and visualization skills using Power BI
